# 更新记录

## v1.0.0 · 2026-10-20

首个公开版本，仓库转为公开并提供预编译 exe。

- Release 附带 `QuarkUpdateHelper-v1.0.0.exe`（18,755,871 字节）
- 提交作者邮箱统一改为 GitHub noreply，避免公开后暴露私人邮箱
- README 增加下载入口

**界面换成简约明亮风**

- 配色改为白卡片 + 极浅灰蓝底 + 单一品牌蓝（跟随 `app.ico`）
- 版本区改成两栏卡片：本地 / 网盘，各带版本号与补充信息
- 状态改成淡色徽章，随状态变色（检查中 / 已是最新 / 失败）
- 修掉三处布局问题：版本卡被 `CTkFrame` 默认 200px 高度撑爆、底栏被日志框挤出窗口、进度条 0% 时残留蓝点
- 设置窗口与扫码窗口统一同一套配色

**打包产物不再内置账号**

- `DEFAULT_CFG.cookie` 置空，删除 `secret_local.py` 分支
- 首次使用与登录过期分开提示
- cookie 为空时不再调用 `verify()`，避免误报「已过期」

## 2026-10-19

**修掉下载必失败的死循环**

- 根因是夸克回收站的墓碑效应：删掉的副本仍会被 `/share/sharepage/save` 认领，
  返回一个已删除的 fid，导致取直链 404
- 改为「先复用网盘已有副本，再转存，下载后不删」
- 删除 `_purge_dupes()`（转存前清空同名副本），它正是墓碑的制造者
- 新增 `_match_existing()`，按同名 + 同大小认领文件

**日志脱敏**

- 异常消息里的签名直链统一抹成 `with url: <path>`
- 覆盖 9 处异常输出与 `待办.txt`

**首次发布**

- 定时查分享、自动转存下载、自动启动
- 微信扫码登录
- 打包为单文件 exe，配置与日志移入隐藏目录
